# グローバル規律

## brain (`~/brain`) の運用

`~/brain` は個人用の Obsidian vault で、日次ログ・プロジェクト状態・意思決定・知識を集約している。

### 作業開始時
- タスクに着手する前に `~/brain` の関連ノートを確認する。最低限、次の3つを見る:
  - `~/brain/daily/` の直近の日次ノート（前回どこまでやったか）
  - `~/brain/projects/<プロジェクト名>.md`（対象プロジェクトの現在地）
  - `~/brain/decisions/` の関連する決定ノート（すでに決まっている方針を蒸し返さない）
- 探すときは `grep -ril "<キーワード>" ~/brain` が早い。
- 既存の決定と矛盾する提案をしそうになったら、まずその決定ノートを読み、覆すなら理由を明示する。

### 記録するとき
- 重要な決定・学びは `~/brain` に記録する。会話の中だけで終わらせない。
  - 方針・技術選定・トレードオフの決着 → `~/brain/decisions/YYYY-MM-DD-要約.md` に**1件1ファイル**で
  - 再利用できる手順・調査結果 → `~/brain/knowledge/`
  - プロジェクトの現在地の変化 → `~/brain/projects/<プロジェクト名>.md` を更新
  - その日の作業ログ → `~/brain/daily/YYYY-MM-DD.md`（SessionEnd フックが自動追記する）
- 日々の些末な作業内容まで書かない。後から参照する価値があるものだけ。

### brain のフォーマット規約（必ず従う）
- **frontmatter 必須**: すべてのノートの先頭に `date` / `project` / `tags` を含む YAML frontmatter を置く。
  ```yaml
  ---
  date: 2026-08-29        # 絶対日付。相対表現は使わない
  project: my-app          # 該当なしは none
  tags: [decision, infra]  # 空にしない
  ---
  ```
- **1ノート1トピック**: 話題が増えたらファイルを分ける（`daily/` のみ時系列追記可）。
- **関連は `[[wikilink]]`**: 他ノートへの参照は必ず `[[ノート名]]` 形式。相対パスやURLで書かない。
  リンク先が未作成でもよい。
- **decisions は1件1ファイル**: 複数の決定を1ファイルにまとめない。背景 / 決定 / 理由 / 見送った案 / 影響 を書く。
- 詳細は `~/brain/README.md` を参照。迷ったらそちらが正。

### 自動化
`~/.claude/hooks/session-end-brain.sh` が SessionEnd で日次ノートへ要約を追記し、`~/brain` にコミットする。
手動で `~/brain` を編集した場合もコミットまで済ませること。
