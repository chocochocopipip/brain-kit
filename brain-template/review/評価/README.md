# 評価（相棒が書く。1 日 1 回）

`YYYY-MM.md` に 1 PR 1 行。月末に集計する。<レビュー担当名>は読むだけ。
新しい月は [[評価/_テンプレート]] を `YYYY-MM.md` に写して始める（列と月次の項目が入っている）。

| PR | 判定 | 確認で見つかった欠陥 | 本番で出た欠陥 | 見逃し | 誤指摘 | 具体度（行・再現あり=○） | 所要 | 規準に足した項目 |
|---|---|---|---|---|---|---|---|---|

月次：見逃し率、誤指摘率、確認で追加で見つかった件数、読み直し（[[読み直し/README]]。答えを伏せて過去の PR を読ませる）の結果、規準の版の動き。
