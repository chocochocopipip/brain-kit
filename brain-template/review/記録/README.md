# 記録（追記専用）

`YYYY-MM-DD.md` に、1 レビュー 1 ブロック。判定を後から書き換えない。訂正は新しいブロックで。

```
## <repo>#<PR> <題名>（YYYY-MM-DD HH:MM、規準 版 N）
- 判定：OK／NG（型 A なら「型 A」）
- 当てた項目：A1 A2 …（結果つき）
- 別モデル：使ったか、採った指摘・採らなかった指摘
- 指摘：
  1. <file:line> — <何が> — <再現／期待> — <直せば OK になる条件>
- 規準外：…
- 所要：NN 分
```
