# 規準の版（前の版の写し）

`規準.md` の版を上げる前に、上げる前の全文をここへ `v<N>.md`（N = 上げる前の版）として写す。**写しは書き換えない。**
記録の「規準 版 N」が当時どの項目を指していたかを、あとから読めるようにするため。

## 版を上げる手順（<レビュー担当名>）

1. `cp review/規準.md review/規準の版/v<N>.md`
2. `規準.md` の項目を足す・変える。見出しの「版 N」を N+1 にする
3. `## 版の履歴` に 1 行（版・日付・変えたこと・きっかけの PR）
4. 足した項目の「過去の PR」に、見逃した PR を紐づける。紐づいた PR は月 1 回の読み直し（[[読み直し/README]]）の候補になる

足すかどうかは相棒の評価（`評価/`）と読み直しの結果で決める。勘で足さない。
