# Evaluation (written by the partner, once a day)

In `YYYY-MM.md`, one line per PR. Totalled at the end of the month. <レビュー担当名> only reads it.
To start a new month, copy [[評価/_テンプレート]] to `YYYY-MM.md` (it has the columns and the monthly items).

| PR | Verdict | Defects found in the check | Defects found in production | Misses | False findings | Concreteness (line and reproduction given = ○) | Time taken | Items added to the criteria |
|---|---|---|---|---|---|---|---|---|

Monthly: miss rate, false finding rate, number of extra defects found in the check, results of the re-read ([[読み直し/README]]; past PRs read with the answers hidden), and how the criteria version moved.
